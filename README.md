# 🔍 OCRCO - 智能截图文字识别工具

OCRCO 是一款基于 **Python + PyQt6** 开发的轻量级 Windows 桌面 OCR 工具。它集成了 **WeChatOCR** 本地引擎，能够快速、精准地识别屏幕截图中的文字，并提供实时翻译功能。

> 🚀 **核心优势**：本地离线识别（保护隐私）、内存自动释放（轻量运行）、极简交互。

---

## ✨ 功能特性 (Features)

* **🎯 极速微信级截图与悬停吸附**：全局快捷键 `Alt + A` 一键唤起，鼠标移动到窗口、子控件或内容卡片上**自动框选吸附**，点击即选中；支持自由拖拽框选、8 方向微调把手及拖拽移动。
* **🎨 选区内即时标注工具栏**：选中后自动唤出现代暗黑悬浮工具条，支持**矩形、椭圆、指向箭头、自由画笔、文字标注**，配备 3 档线宽、6 色精美调色板及 `Ctrl+Z` 步骤撤销。
* **📑 智能排版与表格还原**：独创智能几何分栏与空隙投影算法，支持 4 种排版一键切换（**📑 智能排版**、**📃 自然段落**、**📄 逐行原始**、**📊 Markdown表格**），彻底解决多栏与表格错行问题，智能过滤中英文多余换行空格。
* **🔒 本地离线引擎**：内置 WeChatOCR 引擎，无需联网即可识别，识别率极高，保护隐私安全。
* **🧠 智能内存优化**：独创 "Light Mode" 机制。识别完成后按 `ESC` 或关闭窗口，程序自动释放显存与内存，后台静默占用极低。
* **🌐 辅助翻译**：集成 Google Translate 接口，一键将识别结果翻译为中文或对照查看。
* **📋 自动工作流与开机自启**：识别成功后自动排版并复制文字到剪贴板，支持系统托盘右键一键开启开机自启。
* **👁️ 视觉体验**：高清截图预览，UI 自动缩放，支持多屏及高 DPI 屏幕。

## 🛠️ 安装与运行 (Installation)

### 方式一：下载直接运行 (推荐)
前往本项目的 [Releases](../../releases) 页面下载最新的 `OCRCO-v2.0.0-windows-x64.zip` 压缩包。
1. 解压压缩包。
2. 双击运行 `OCRCO.exe` 即可使用（无需配置任何 Python 环境）。

### 方式二：从源码运行

如果你是开发者，想自己修改代码：

```bash
# 1. 克隆仓库
git clone https://github.com/eielyving/OCRCO.git
cd OCRCO

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行
python main.py
```
  注意：本项目依赖 `ocr_engine` 文件夹中的二进制文件，请确保该文件夹完整存在。使用翻译功能需自行配置网络环境。

## 🎮 使用指南 (Usage)
### 操作说明
 | 操作 | 说明 | 
 | ------ | ------ | 
 | **Alt + A** | 唤起截图 (全局热键) | 
 | **鼠标悬停** | 智能自动感知并框选窗口、子面板或规整卡片 | 
 | **鼠标左键点击/拖拽** | 确定智能框选或手动拖拽自由框选 | 
 | **选区标注栏** | 标注矩形、椭圆、箭头、自由涂鸦或文字 (可撤销 Ctrl+Z) | 
 | **Enter / 识别** | 执行高精度 OCR 文字识别并打开排版界面 | 
 | **Ctrl + C / 复制** | 复制当前带标注的截图到系统剪贴板 | 
 | **鼠标右键** | 退出当前标注 / 重置框选 / 退出截图 | 
 | **ESC** | 隐藏窗口并进入*静默省电模式* (释放内存) | 
 | **系统托盘图标** | 右键托盘图标可唤出窗口、开机自启开关、彻底退出 |

## 📦 编译构建 (Build)
### 如果你修改了代码并想重新打包成 EXE：

1. 确保安装了 PyInstaller：
```pip install pyinstaller```
2. 使用项目自带的配置文件进行打包：
```pyinstaller OCRCO.spec```
3. 打包完成后，在 ```dist``` 文件夹中找到 ```OCRCO.exe```。

4. 重要：将根目录下的 ```ocr_engine``` 文件夹手动复制到 ```dist``` 文件夹中，与 exe 同级，否则无法识别
